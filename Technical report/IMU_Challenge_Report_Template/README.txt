IMU Odometry Challenge — Technical Report Template
==================================================

Contents
  main.tex        the template (edit this one)
  ieeeconf.cls    IEEE conference class, required; do not modify

Overleaf
  New Project -> Upload Project -> select this .zip -> Recompile.
  Nothing else to install.

Local (TeX Live / MacTeX)
  pdflatex main.tex   (run it three times, so that the cross-references settle)
  No .bib file is needed: the bibliography is inline in main.tex.

Before you submit, please check
  * 6 pages excluding references, 7 pages in total including references.
    The appendix does not count towards either limit.
  * Every number in Tables III, IV and V comes from the official scoring service
    https://huggingface.co/spaces/Tartan-IMU/imu_odometry_challenge_scoring
    and NOT from a local re-implementation. State the MD5 of the submission CSV.
  * The compliance declaration (Section VI) is answered in full.
  * The report is submitted inside the challenge Form, not on the website.

Latest rules and any change to the deadlines are posted in the Announcements
section of https://superodometry.com/imuchallenge
